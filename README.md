### ✨ Features

- **Hero Banner:** Features trending collections, price cards, and soft CTA options.
- **Product Spotlight:** Clean grid layouts for curated home & kitchen items.
- **Inspiration & Care:** Blog section with decor tips and home care guides.
- **Trust Badges:** Highlights for free shipping, easy returns, secure checkout, and 24/7 support.

### 🛠️ Built With

- **HTML5** — Semantic, clean page structure
- **CSS3** — Custom styling powered by CSS Grid & Flexbox
